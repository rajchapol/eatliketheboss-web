## 4. สิ่งที่ทำไปตั้งแต่ deploy แรก (สรุป)
- **รื้อ UI/UX ทั้งเว็บ:** มุมโค้ง เงานุ่ม อ่านง่าย ฟอนต์ self-host รูปอาหาร 3:2 ทุกที่ (ใช้ crop/hotspot จาก Studio)
- **หน้าแรก:** สไลด์ 5 ร้านล่าสุด · The Index (เดือนที่ไป + รูป) · Glasses Off ตามปี · ไม่ไฮไลต์เมนูใดในหน้าแรก
- **Glasses Off Awards:** แว่นรวงผึ้ง แว่นดำ→สว่าง · **จุดหมาย:** ไทย + ทวีป → ประเทศ + แผนที่จุดไข่ปลา (ซูม โลก/เอเชีย/ไทย)
- **หน้าเมือง:** Boss's Picks (ตั้งใน Studio), กรองประเภทอาหาร, ร้านที่ไปซ้ำรวมแถวเดียว · มือถือเป็นรายการรูปซ้าย-ข้อความขวา
- **หน้ารีวิว:** กล่อง **"สรุปสั้น / At a glance"** (ระดับราคา ประเภท รางวัล เมือง ปุ่มไปจานถอดแว่น ปุ่มดูทุกจาน) · ย่อหน้าแรกตัวใหญ่ · **ประโยคเด่นของบอส**เป็นคำคม · แถบแชร์ LINE/Facebook/คัดลอกลิงก์ · ไปร้านซ้ำมีแถบรายการทุกครั้ง · More Tasting Notes (เมืองเดียวกันก่อน) + ลิงก์ "ดูทุกร้านใน<เมือง>"
- **ระดับราคา** ฿฿/฿฿฿/฿฿฿฿ + ป้าย Event/AD · แสดงเป็นแคปซูลบนการ์ด
- **เมนู:** ไอคอน + ชื่ออังกฤษ + ไทยตัวเล็ก · มือถือ 5 แท็บพอดีจอ 320px · แถบเมนูกระจกตอนเลื่อนขึ้น
- **ภาษา:** ปุ่ม "อ่านภาษา" อยู่ในบทความ (ไม่อยู่หัวเว็บ) · **ไม่มีแปลอัตโนมัติ** (Google Translate พัง 2 รอบ บอสสั่งปิดถาวร) · แปลเฉพาะหน้าบทความ · มีคำแปลอังกฤษ 6 ร้านแล้ว
- **เอฟเฟกต์สงบ:** reveal, การ์ดเอียง, spotlight, count-up · ไม่มี page transition · ไม่เล่นซ้ำเมื่อกด Back · ปิดหมดเมื่อผู้ใช้ตั้งลดการเคลื่อนไหว
- **หน้าอื่น:** `/contact/` (ฟอร์มส่งอีเมลผ่าน Web3Forms) · 404 มีช่องค้นหา + รีวิวล่าสุด · RSS `/rss.xml` (บอสให้เก็บไว้) · sitemap · hreflang
- **ประสิทธิภาพ:** หน้าบีบอัด ~17–20KB · โลโก้ย่อขนาด · สคริปต์ย่อ/รวม · CSS ฝังในหน้า (ตั้งใจ — คนส่วนใหญ่เข้าจาก LINE ทีละบทความ)
- **รูปแชร์อัตโนมัติ** ต่อบทความ วางทุกอย่างกลางภาพให้ LINE ครอปได้
- **หลังบ้าน (Studio):** แท็บเรียงตามลำดับกรอก, ระบบคำแปลกดปุ่มเดียว, เมนู "งานที่ต้องทำ", ปุ่มเปิดดูบนเว็บ / ลบอย่างปลอดภัย, ตัวนับตัวอักษร SEO, ข้อความทุกหน้าแก้ได้
- **ลงบทความจากไฟล์:** แก้ไฟล์ซ้ำได้ ระบบส่งเฉพาะช่องที่แก้ ไม่ทับสิ่งที่บอสแก้ใน Studio

## 5. กฎที่ต้องรักษา
**แบรนด์**
- ไม่มีดาว/คะแนน (ไม่มี reviewRating ใน JSON-LD) · ระดับราคา ฿฿/฿฿฿/฿฿฿฿ เท่านั้น ห้ามราคาจริง ห้ามบอกมื้อเชิญ/จ่ายเอง · ป้าย Event / AD
- ไอคอนเส้นชุดเดียว **ห้ามอีโมจิใน UI** · รูปอาหาร 3:2 · มุมโค้ง: ปุ่ม=แคปซูล, การ์ด/รูป 20/28px
- ลายประจำเมืองไม่มีป้ายข้อความ · Boss's Pairing เลิกใช้ · ห้ามระบุที่ทำงานของบอส
- สี: teal `#0b5357`, teal deep `#073b3e`, gold `#c39e5c`, gold light `#fdeac0`, paper `#f4ece0`, card `#fbf7ef`, ink `#1a2632` · ฟอนต์: Noto Serif Thai / Cormorant Garamond / Ekkamai New
- **ภาษาไทยห้าม letter-spacing กว้าง**

**เทคนิค**
- URL ที่ live แล้วห้ามเปลี่ยน: `/review/<city>/<slug>/` · `/history/<slug>/` · `/drinks/<slug>/` · `/city/<slug>/` · `/restaurants/` · `/destinations/` · `/glasses-off-awards/` · `/about/` · ภาษาอื่นนำหน้า `/en/ /ja/ /zh/` (ถ้าจำเป็นใช้ redirect)
- เลข Tasting Notes No. นับอัตโนมัติจากเดือน Visit
- UI ที่ `position:fixed` **ห้ามอยู่ใน `.elb-page`** (Safari ผูก fixed กับ container) · CSS มือถือของ element นอก container ใช้ `@media`
- เอฟเฟกต์ทั้งหมดต้องอยู่ใต้ `.fx-on` (ปิดเมื่อ reduced motion) · ไม่มี page transition
- เปลี่ยนดีไซน์รูปแชร์ → เพิ่มเลข `?v=` ของ og:image (LINE/Facebook จำรูปตาม URL)
- ใน Studio อย่าใช้ `<Text>` ของ @sanity/ui กับข้อความไทยหลายบรรทัด (สระทับกัน) ใช้ `studio/components/Line.tsx`
- workflow ที่แก้ข้อมูลจริงต้องกดเอง (dry ก่อน) · **ห้ามขอ/เก็บ token** บอกบอสว่าวางที่ไหน
- ถามบอสก่อนเปลี่ยนสิ่งที่กระทบวิธีถ่ายรูปหรือเขียน และเช็คข้อมูลจริงก่อนเสมอ

## 6. วิธีใช้ระบบหลังบ้าน (Studio) — ส่วนที่ฝ่ายเว็บต้องรู้
- **ตั้งค่าเว็บ / ข้อความทุกหน้า:** แท็บตามหน้า (หน้าแรก · บทความ · ค้นหาร้าน · จุดหมาย · Awards · ซีรีส์ · เกี่ยวกับบอส · ติดต่อ · ท้ายเว็บ & SEO) ทุกข้อความบนเว็บมาจากที่นี่ · ถ้าเพิ่มข้อความใหม่ในโค้ด ต้องเพิ่มช่องใน Studio + ค่าเริ่มต้น แล้วรัน GitHub Actions → "Fill settings texts" (dry ก่อน)
- **บทความ:** แท็บ 1 ร้าน & บทนำ · 2 รายการจาน · 3 ราคา & วันที่ไป · 4 SEO (ตัวนับ) · 5 ภาษา / คำแปล (ปุ่ม "+ English" สร้างคำแปลที่ผูกให้เอง) · ช่องภาษาล็อกไว้
- **ปุ่ม:** เปิดดูบนเว็บ · ลบบทความ… (ลบร่าง+เผยแพร่ ปิดหน้าให้)
- **งานที่ต้องทำ:** ร่างค้าง ภาษาเพี้ยน ไม่มีระดับราคา/Visit/ปก/alt SEO ไม่ครบ ยังไม่มีคำแปลอังกฤษ
- **เมือง:** ภูมิภาค + ประเทศ (จัดกลุ่มหน้าจุดหมาย), ตำแหน่งบนแผนที่, Boss's Picks (สูงสุด 3), ภาพเมือง, ลาย motif
- **Analytics:** Cloudflare Web Analytics (token ใน Studio → ติดต่อ & SEO) · นับยอดเข้าชมได้ แต่นับการกดปุ่มไม่ได้

## 7. วิธีทดสอบ (แบบ ข)
- Container ของ Claude Code มักเข้า Sanity/เว็บจริงไม่ได้ → ทดสอบด้วย `SANITY_PROJECT_ID=sample npm run build` หรือสร้างข้อมูลตัวอย่างชั่วคราวจากบทความจริงใน `posts/*.md` + รูป `posts/images/` (วิธีใน `docs/HANDOFF.md` หัวข้อ "Bug check with real content") — **อย่า commit ไฟล์ชั่วคราว**
