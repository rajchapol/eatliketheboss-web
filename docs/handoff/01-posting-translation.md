## 2. ทำงานได้ 2 แบบ — เลือกตามว่าคุณเข้า GitHub ได้หรือไม่

### แบบ ก · เข้า GitHub ไม่ได้ (แชท Claude ทั่วไป)
ส่งงานให้บอสเป็นข้อความ แล้วบอสเลือกทางใดทางหนึ่ง:
1. **ส่งเป็นไฟล์บทความ** ตามแม่แบบในหัวข้อ 3 (ทั้งไฟล์ในกล่องโค้ดเดียว + รายชื่อรูปที่ต้องใช้ตามชื่อไฟล์) → บอสนำไปให้ Claude ที่เข้า GitHub ได้ลงให้
2. **ส่งเป็นข้อความแยกตามช่องใน Studio** (เรียงตามแท็บในหัวข้อ 6) → บอสก๊อปวางในหลังบ้านเอง แล้วอัปโหลดรูปเอง

### แบบ ข · เข้า GitHub ได้ (Claude Code ที่ต่อ repo)
1. เขียนบทความในน้ำเสียงบอส (skill `eatliketheboss-writing-style` ถ้ามี · Google Doc ของบอสเป็นต้นฉบับ)
2. สร้าง `posts/<slug>.md` ตามแม่แบบ รูปไว้ที่ `posts/images/<slug>/`
3. ตรวจด้วย `npm run post -- posts/<slug>.md --dry`
4. **รอบอสอนุมัติก่อนเสมอ** แล้ว commit ไฟล์ + รูป push เข้า `main` (หรือเปิด PR ให้บอส merge) → GitHub Actions ลงเข้า Sanity ให้เอง · **ห้ามขอหรือเก็บ token ใดๆ**
5. **แก้ไฟล์ที่ลงไปแล้วได้ตลอด:** ระบบส่งเข้า Sanity เฉพาะช่องที่แก้ในไฟล์ (เทียบกับไฟล์ฉบับก่อน) สิ่งที่บอสแก้ใน Studio ช่องอื่นไม่ถูกแตะ · ถ้าแก้ช่องเดียวกันทั้งสองที่ ค่าในไฟล์ล่าสุดชนะ · เพิ่ม/ลบจาน = รายการจานทั้งชุดตามไฟล์ · **slug เปลี่ยนไม่ได้** (URL จะเสีย)

## 3. แม่แบบไฟล์บทความ (ใช้ได้ทั้งแบบ ก และ ข)
```markdown
---
language: th            # th | en | ja | zh (คำแปลใช้ slug เดียวกับต้นฉบับไทย)
series: review          # review (บอสพาชิม) | history (มื้ออาหารเปลี่ยนโลก, ใส่ episode) | drinks (บอสพาดื่ม)
title: "บอสพาชิม in Tokyo: ชื่อร้าน (ชื่อเดิม) - คำโปรยเชิงศิลปะ"
slug: restaurant-name   # อังกฤษตัวเล็ก คั่นด้วย - · ตั้งแล้วห้ามเปลี่ยน
tagline: "คำโปรยเชิงศิลปะ"
city: tokyo             # slug เมืองใน Sanity เช่น shanghai, tokyo, bangkok
restaurant:
  name: "ชื่อร้าน"
  originalName: "ชื่อภาษาเดิม"
  chef: "ชื่อเชฟ"
  area: "Ginza"
  cuisine: "ญี่ปุ่น"     # ญี่ปุ่น | ไทย | ฝรั่งเศส | จีน | อิตาเลียน | สเปน | Modern | อื่นๆ
  awards: ["MICHELIN 2★"]
  # sameAs: old-slug     # ถ้าร้านเปลี่ยนชื่อ: slug ของรีวิวครั้งก่อน
cover: "./images/restaurant-name/cover.jpg | alt บรรยายภาพจริง + ชื่อร้าน + เมือง"
# gallery:               # ไม่บังคับ 1–6 รูป: รูป | alt | คำบรรยาย
#   - "./images/restaurant-name/room.jpg | ห้องอาหารวิวแม่น้ำ ร้าน X | ห้องอาหารชั้น 56"
quote: ""               # ไม่บังคับ: ประโยคเด่นของบอส ขึ้นเป็นคำคมตัวโตหลังบทนำ

publishedAt: 2026-11-05
seoTitle: "ชื่อร้าน Tokyo รีวิว Fine Dining"      # ≤ 60 ตัวอักษร
seoDescription: "120–155 ตัวอักษร น้ำเสียงบอส บอกจุดเด่น เมือง ประเภทอาหาร ห้ามดาว/คะแนน"
```

## 4. กฎเนื้อหา (สำคัญ)
- **ห้ามดาว ห้ามคะแนน** (ยกเว้นชื่อรางวัลจริงในช่อง awards เช่น "MICHELIN 1★")
- **The Boss's Bill = ระดับราคาโดยประมาณเท่านั้น** ฿฿ / ฿฿฿ / ฿฿฿฿ · **ห้ามบอกราคาจริงในเนื้อหา และห้ามบอกว่ามื้อนี้ได้รับเชิญหรือจ่ายเอง** · มื้อพิเศษ → `Event` · รับค่าจ้าง → `AD`
- Boss's Pairing เลิกใช้แล้ว ห้ามใส่กลับ
- ห้ามระบุชื่อที่ทำงานของบอส · ประวัติใช้: "Hospitality และ F&B มากว่า 15 ปี" · กรรมการ: "Tatler Best Asia-Pacific panelist & more"
- จานถอดแว่น 🕶️ สูงสุด 2 จานต่อมื้อ
- **เลข Tasting Notes No. ระบบนับเอง** จากเดือน Visit (มื้อเก่าสุด = No. 001) ห้ามตั้งเอง
- ไปร้านเดิมซ้ำ: ชื่อร้านต้องสะกดเหมือนเดิมทุกตัว (เมืองเดียวกัน) เว็บรวมเป็นร้านเดียวให้ · ร้านเปลี่ยนชื่อ → `sameAs`
- SEO: slug ภาษาอังกฤษ · Meta title ≤ 60 · description 120–155 · ทุกรูปมี alt · ใส่วันเผยแพร่และเมือง

## 5. รูป
- **รูปอาหารทุกที่แสดงแนวนอน 3:2** (ภาพบอสส่วนใหญ่ 1225×815 อยู่แล้ว)
- **รูปปก = รูปแชร์ใน LINE/Facebook** ระบบสร้างให้เอง (ปก + โลโก้ + ชื่อร้าน + No. วางกลางภาพ เพราะ LINE ครอปสี่เหลี่ยม) → เลือกปกที่ **จุดเด่นอยู่กลางภาพ** · ตัวจีน/ญี่ปุ่นไม่ขึ้นบนรูปแชร์ (ขึ้นบนหน้าเว็บปกติ)
- `gallery` = รูปบรรยากาศ/เชฟ แสดงหลังบทนำ ก่อนรายการจาน
- alt ทุกรูป: บรรยายสิ่งที่เห็นจริง + ชื่อร้าน + เมือง เช่น "เป๋าฮื้อตุ๋นบนช้อนกระเบื้องสีขาว ร้าน Meet The Bund at Skyline เซี่ยงไฮ้"

## 6. วิธีใช้ระบบหลังบ้าน (Studio)

**เมนูซ้าย:** บทความ (ภาษาไทย) — ทั้งหมด / ตามซีรีส์ / ตามเมือง · คำแปล (EN / 日本語 / 中文) · **งานที่ต้องทำ** (ภาษาเพี้ยน, ร่างค้าง, ไม่มีระดับราคา/Visit/ปก/alt, SEO ไม่ครบ, ยังไม่มีคำแปล EN — รายการหายเองเมื่อแก้เสร็จ) · เมือง · ตั้งค่าเว็บ / ข้อความทุกหน้า

**แท็บในบทความ (เรียงตามลำดับที่กรอก):**
1. **ร้าน & บทนำ** — ซีรีส์ ชื่อบทความ slug คำโปรย เมือง ข้อมูลร้าน (ชื่อ ชื่อเดิม เชฟ ย่าน ประเภท รางวัล รีวิวครั้งก่อน) รูปปก แกลเลอรี บทนำ **ประโยคเด่นของบอส**
2. **รายการจาน** — ชื่อจาน (ชื่อเดิม) คำบรรยาย ติ๊ก "ถอดแว่นชิม" รูปจาน
3. **ราคา & วันที่ไป** — The Boss's Bill · มื้ออีเวนต์? (ไม่ใช่ / Event / AD) · ราคาจริง (ไม่แสดง) · Visit · แฮชแท็ก · วันที่เผยแพร่
4. **SEO** — Meta title / description พร้อม**ตัวนับตัวอักษร**บอกขาด/เกินกี่ตัว
5. **ภาษา / คำแปล** — แผงแสดงทุกภาษาของบทความ + ปุ่มสร้างคำแปล
- "ทุกช่อง" = ดูทุกช่องในหน้าเดียว

**ปุ่มข้าง Publish:** **เปิดดูบนเว็บ** (ต้องเผยแพร่ก่อน) · **ลบบทความ…** (บอกก่อนว่าหน้าไหนจะหาย ลบร่าง+ฉบับเผยแพร่ ถ้ามีคำแปลผูกอยู่ต้องลบคำแปลก่อน)

## 7. คำแปล
**ใน Studio:** เปิดบทความไทยที่เผยแพร่แล้ว → แท็บ 5 → กด **+ English / 日本語 / 中文** → ระบบสร้างร่างที่ผูกกับบทความไทย คัดลอกร้าน รูป จาน ราคา Visit slug และข้อความไทยมาให้แปลทับ (SEO ต้องเขียนใหม่) · มีอยู่แล้วปุ่มจะเปิดอันเดิม
- ช่อง "บทความนี้เป็นภาษา" **ล็อกไว้** ห้ามเปลี่ยนบทความไทยเป็นภาษาอื่น · ถ้าเจอบทความไทยภาษาเพี้ยน กด **"เปลี่ยนกลับเป็นบทความภาษาไทย"** ในแท็บ 5

**เป็นไฟล์:** แม่แบบเดียวกัน `language: en` · **slug เดียวกับต้นฉบับ** · ไฟล์ชื่อ `posts/<slug>.en.md` (แบบ ข: ร่างไว้ที่ `drafts/translations/` ก่อน บอสอนุมัติแล้วค่อยย้ายเข้า `posts/`) · ถ้า Studio มีร่างคำแปลของร้านนั้นอยู่ ให้ลบร่างก่อน

**หลักการแปล:**
- ชื่อร้าน ชื่อจาน ชื่อเชฟ **คงตามต้นฉบับ** (หัวจาน `###` ที่เป็นชื่อจีน/อังกฤษเดิม ห้ามแปล · ถ้าเป็นภาษาไทยล้วนค่อยแปล)
- น้ำเสียงนักวิจารณ์ของบอส บุรุษที่หนึ่ง อบอุ่น ประณีต · ห้ามเติมข้อมูล/รางวัลที่ต้นฉบับไม่มี
- ชื่อบทความอังกฤษ: "Eat Like The Boss in <City>: <Restaurant> - <tagline>" · hashtag บอสพาชิม → EatLikeTheBoss
- alt รูปแปลด้วย · ไม่ใส่ราคาจริง/มื้อเชิญ
- คำที่บอสยืนยันแล้ว: หอยปีกนก = **torigai** (Japanese cockle) · ใบชะพลู = **betel leaves** · ลิลลี่บับ = **lily buds**
- คำที่ไม่แน่ใจ ให้เลือกคำที่น่าจะถูกแล้ว **ลิสต์ส่งบอสยืนยันท้ายงาน**

**บนเว็บ:** ปุ่ม "อ่านภาษา: ไทย · English" อยู่ใต้ breadcrumb ของบทความ ขึ้นเฉพาะบทความที่มีคำแปลจริง

## 8. งานค้าง / ข้อเสนอแนะ
1. แปลบทความใหม่ทุกเรื่องเป็นอังกฤษในรูปแบบเดิม (ส่งบอสอนุมัติก่อนลง)
2. ญี่ปุ่น/จีนยังไม่มี · ถ้าเริ่ม แนะนำร้านในญี่ปุ่น → ภาษาญี่ปุ่นก่อน
3. ตั้งระดับราคาให้ครบทุกบทความ (Studio → งานที่ต้องทำ → ยังไม่มีระดับราคา)
4. ใส่ "ประโยคเด่นของบอส" ในบทความเด่นๆ
5. ถ้าบอสเปิด LINE OA: RSS **https://eatlikeboss.com/rss.xml** ใช้ส่งแจ้งเตือนบทความใหม่อัตโนมัติได้
6. ร่างค้างใน Studio ของ Meet The Bund / Sui Tang Li / Yong Fu (จากช่วงทดสอบระบบแปล) ให้บอสกด "เปลี่ยนกลับเป็นบทความภาษาไทย" หรือ Discard changes
