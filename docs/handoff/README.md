# Hand-off by role

Short hand-offs for the Claude chats that work on this project, each covering what it needs: what was done since the first deploy, how the new Studio works, the rules, and suggestions.

Each file stands alone: it can be pasted into a chat that has no GitHub access. It holds the article template, the brand values, the live site and Studio links, and what to hand back when the chat can't touch the repo.

| File | For |
| --- | --- |
| `01-posting-translation.md` | Posting articles, translations and photos |
| `02-brand-graphics.md` | Brand, design system and graphics |
| `03-web-design.md` | Website design and code |

The full technical log, newest first, is `docs/HANDOFF.md`. Rules for everyone are in `CLAUDE.md`.
