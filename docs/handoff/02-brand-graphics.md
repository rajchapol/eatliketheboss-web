### ฟอนต์ (self-host บนเว็บ ไม่ใช้ Google Fonts · ลิขสิทธิ์ SIL OFL)
- **Noto Serif Thai** 400/600/700 — หัวข้อและเนื้อความ ไทย+อังกฤษ · เนื้อความไทยใช้ 400 (บางกว่านี้อ่านยากบนพื้นเข้ม)
- **Cormorant Garamond** 500 ตัวตรง/เอียง — "Tasting Notes", เลข No., หัวข้ออังกฤษเชิงศิลป์ (เช่น "The Index", "Boss's Picks")

- **ภาษาไทยห้ามเว้นระยะตัวอักษรกว้าง** (สระ/วรรณยุกต์จะแตก) · letter-spacing ใช้กับตัวอังกฤษพิมพ์ใหญ่เท่านั้น เช่น "TASTING NOTES"

### รูปทรง / พื้นผิว / ไอคอน
- มุมโค้ง: ปุ่มและป้าย = แคปซูล · การ์ดและรูป = 20px / 28px · เงานุ่ม (ไม่ใช้บล็อกทองแข็งแบบเก่า)
- ลายประจำเมือง (Seigaiha โตเกียว, Shippo เกียวโต, Kikko โอซาก้า ฯลฯ) **เป็นลายตกแต่งเท่านั้น ห้ามมีป้ายข้อความ "ลายประจำเมือง"**
- ไอคอน: line icons ชุดเดียว เส้น 1.5px ปลายมน สีทอง/เขียว · **ห้ามใช้อีโมจิในหน้าเว็บ**

### ภาพ
- **รูปอาหารทุกที่ = แนวนอน 3:2** (ปก จาน การ์ด รางวัล)
- **รูปแชร์บทความ 1200×630** (ระบบสร้างเองทุกบทความ): ภาพปกสีจริง มืดเฉพาะด้านบน (หลังโลโก้) และล่าง (หลังตัวอักษร) · โลโก้ทองกลางบน → "Tasting Notes No. 00X" → ชื่อร้าน (สูงสุด 2 บรรทัด) → เมือง · ประเภท · **ทุกอย่างอยู่ในกรอบกลาง 560px** เพราะ LINE ครอปเป็นสี่เหลี่ยม · ไม่มีตัวจีน/ญี่ปุ่นบนรูป (ฟอนต์ไม่มี)

## 4. กฎแบรนด์ด้านเนื้อหา (ใช้กับกราฟิกด้วย)
- **ไม่มีดาว ไม่มีคะแนน** · ความประทับใจสื่อผ่านงานเขียนและ **จานถอดแว่น 🕶️** (สูงสุด 2 จานต่อมื้อ) ประโยคประจำ: "จานนี้อร่อยจนบอสต้องขอถอดแว่นชิม"
- **The Boss's Bill = ระดับราคาโดยประมาณ** ฿฿ / ฿฿฿ / ฿฿฿฿ เท่านั้น · ห้ามราคาจริง · **ห้ามบอกว่ามื้อเชิญหรือจ่ายเอง** · มื้อพิเศษใช้ป้าย **Event** · โพสต์รับค่าจ้างใช้ **AD**
- ห้ามระบุชื่อที่ทำงานของบอส · ประวัติ: "Hospitality และ F&B มากว่า 15 ปี" · กรรมการ: "Tatler Best Asia-Pacific panelist & more"
- Boss's Pairing เลิกใช้แล้ว
- ชื่อ: ไทย **บอสพาชิม** / อังกฤษ **Eat Like The Boss** · ซีรีส์: บอสพาชิม (รีวิวร้าน), มื้ออาหารเปลี่ยนโลก, บอสพาดื่ม · รางวัล: **Glasses Off Awards** (ไทยตัวเล็ก "รางวัลถอดแว่น") · ชื่อบันทึกการชิม: **Tasting Notes No.** (เลขนับตามเดือนที่ไป)

## 5. สิ่งที่เปลี่ยนบนเว็บตั้งแต่ deploy แรก (ส่วนที่เกี่ยวกับแบรนด์)
- ภาพรวมทันสมัยขึ้น: มุมโค้งทุกที่ เงานุ่ม ตัวหนังสือบนพื้นเข้มชัดขึ้น · ฟอนต์ทั้งหมด self-host
- **เมนูเว็บ:** ไอคอน + ชื่ออังกฤษ (Restaurants / Destinations / Tasting Notes / Glasses Off Awards / About the Boss) + ไทยตัวเล็กใต้ · มือถือใช้ชื่อสั้น Search / Cities / Notes / Awards / About
- **หน้า Glasses Off Awards:** แว่นที่เลนส์เป็นรวงผึ้งรูปจาน เริ่มเป็นแว่นดำแล้วค่อยสว่าง (คอนเซปต์ "ถอดแว่น") + ตราประทับปีล่าสุด
- **หน้าจุดหมาย:** แผนที่โลกจุดไข่ปลา หมุดทอง เส้นทางตามลำดับที่ไป
- **หน้ารีวิว:** กล่อง "สรุปสั้น" บนสุด (ระดับราคา ประเภท รางวัล เมือง ปุ่มไปจานถอดแว่น) · ย่อหน้าแรกตัวใหญ่สีเขียว · ประโยคเด่นของบอสเป็นคำคมตัวโต · ป้ายระดับราคาแบบแคปซูล
- **รูปแชร์อัตโนมัติ** ต่อบทความ (ออกแบบรอบสองให้เหมาะกับ LINE)
- **เอฟเฟกต์สงบ:** ค่อยปรากฏตอนเลื่อน แถบเมนูกระจก การ์ดเอียงตามเมาส์ · **ไม่มีเปลี่ยนหน้าแบบแอนิเมชัน** (บอสบอกว่ามึน)
- กันก๊อป: รูปคลิกขวา/ลาก/กดค้างไม่ได้ · ข้อความที่ก๊อป 80 ตัวขึ้นไปแนบเครดิต + ลิงก์ · บล็อกบอท AI ที่เก็บข้อมูลไปเทรน

## 6. ข้อความบนเว็บที่บอสแก้เองได้ (Studio → ตั้งค่าเว็บ / ข้อความทุกหน้า)
แท็บ: **หน้าแรก** (คำโปรย หัวข้อ ช่องค้นหา) · **บทความ** (หัวข้อรายการจาน ประโยคถอดแว่น หัวข้อแชร์) · **ค้นหาร้าน** · **จุดหมาย** (หัวข้อ คำแนะนำ ชื่อแผนที่) · **Awards** (คำแนะนำ) · **ซีรีส์** (คำอธิบาย 3 ซีรีส์) · **เกี่ยวกับบอส** (หัวข้อ ประวัติ สถิติ "ทำไมรีวิวตรงไปตรงมา" "วิธีรีวิว" ร่วมงาน) · **ติดต่อ** (ฟอร์ม อีเมล) · **ท้ายเว็บ & SEO** (ข้อความลิขสิทธิ์ คำอธิบายเว็บ รูปแชร์ ลิงก์ Facebook/Instagram)

## 7. ข้อเสนอแนะ
1. **ชุดเทมเพลตโซเชียล** ภาษาเดียวกับรูปแชร์เว็บ (ปกสีจริง + โลโก้กลาง + ชื่อร้าน + Tasting Notes No.) สำหรับ IG post/story และ Facebook
2. **ป้าย/สติกเกอร์ "Glasses Off" ให้ร้าน** ใช้ glasses-off-badge + ตราประทับปี เป็นการตลาดย้อนกลับมาที่เว็บ
3. **ภาพประจำเมือง** โทนเดียวกัน สำหรับหน้าเมืองและการ์ดเมือง
4. **โลโก้สีเดียว (monochrome)** สำหรับวางบนรูปสว่าง
5. **ฟอนต์ CJK บนรูปแชร์** ถ้าอยากให้ชื่อจีน/ญี่ปุ่นขึ้นบนรูป (ฝ่ายเว็บทำ ไฟล์ฟอนต์ใหญ่)
6. ทบทวนป้าย **AD**: ถ้าบอสไม่รับงานโฆษณาเลย อาจตัดตัวเลือกนี้ออก
