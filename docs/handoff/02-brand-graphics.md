### ฟอนต์ (self-host ใน `public/fonts/` + ไฟล์ลิขสิทธิ์ SIL OFL, ไม่ใช้ Google Fonts)
- **Noto Serif Thai** 400/600/700 — หัวข้อและเนื้อความ (ไทย+ละติน) · เนื้อความไทยใช้น้ำหนัก 400 (300 อ่านยากบนพื้นเข้ม)
- **Cormorant Garamond** 500 ตัวตรง/เอียง — "Tasting Notes", No., หัวข้ออังกฤษเชิงศิลป์

## 3. สิ่งที่เปลี่ยนไปตั้งแต่ deploy แรก (ส่วนที่เกี่ยวกับแบรนด์)
- ปรับภาพรวมให้ทันสมัยขึ้น: มุมโค้งทุกที่ เงานุ่ม ตัวหนังสือบนพื้นเข้มชัดขึ้น
- ฟอนต์ทั้งหมด self-host
- หน้า Glasses Off Awards: แว่นที่เลนส์เป็นรวงผึ้งรูปจาน เริ่มเป็นแว่นดำแล้วค่อยสว่าง (คอนเซปต์ "ถอดแว่น") + ตราประทับปีล่าสุด
- หน้าจุดหมาย: แผนที่โลกจุดไข่ปลา หมุดทอง เส้นทางตามลำดับที่ไป
- รูปแชร์อัตโนมัติต่อบทความ (ออกแบบรอบสองให้เหมาะกับ LINE)
- เมนูเว็บเป็นภาษาอังกฤษ + ไทยตัวเล็ก (มือถือใช้ชื่อสั้น Search / Cities / Notes / Awards / About)
- เอฟเฟกต์: เลื่อนแล้วค่อยปรากฏ แถบเมนูกระจกตอนเลื่อนขึ้น การ์ดเอียงตามเมาส์ · **ไม่มีเปลี่ยนหน้าแบบแอนิเมชัน** (บอสบอกว่ามึน) · ปิดทั้งหมดเมื่อผู้ใช้ตั้งลดการเคลื่อนไหว
- กันก๊อป: รูปคลิกขวา/ลาก/กดค้างไม่ได้ ข้อความที่ก๊อป 80 ตัวขึ้นไปแนบเครดิต + ลิงก์ บล็อกบอท AI ที่เก็บข้อมูลไปเทรน

## 4. ข้อความทั้งเว็บแก้ได้ใน Studio
Studio → **ตั้งค่าเว็บ / ข้อความทุกหน้า** แบ่งแท็บตามหน้า: หน้าแรก · บทความ · ค้นหาร้าน · จุดหมาย · Awards · ซีรีส์ · เกี่ยวกับบอส · ติดต่อ · ท้ายเว็บ & SEO
- ทุกช่องมีข้อความปัจจุบันของเว็บอยู่แล้ว (ค่าเริ่มต้นใน `src/data/settings.json`)
- ถ้าจะเปลี่ยนคำโปรย tagline คำบรรยายแบรนด์ ประวัติบอส ข้อความ "วิธีรีวิว" ทำที่นี่ได้เลย ไม่ต้องแก้โค้ด
- รูปแชร์หน้าทั่วไป, ลิงก์ Facebook/Instagram, อีเมลติดต่อ อยู่ในแท็บ "ติดต่อ" และ "ท้ายเว็บ & SEO"

## 5. ข้อเสนอแนะสำหรับฝ่ายแบรนด์/กราฟิก
1. **ชุดเทมเพลตโซเชียล** ที่ใช้ภาษาเดียวกับรูปแชร์เว็บ (ปกสีจริง + โลโก้กลาง + ชื่อร้าน + No.) สำหรับ IG post/story และ Facebook ให้ทุกช่องทางหน้าตาเป็นชุดเดียวกัน
2. **ป้าย "Glasses Off" สำหรับร้าน** (ใบประกาศ/สติกเกอร์ที่ร้านติดได้) ใช้ `brand/glasses-off-badge.svg` + ตราประทับปี เป็นการตลาดย้อนกลับมาที่เว็บ
3. **ภาพประจำเมือง** สำหรับหน้าเมือง/การ์ดเมือง (ตอนนี้ใช้ภาพปกเมืองจาก Studio + ลาย motif) ถ้ามีชุดภาพถ่ายเมืองโทนเดียวกันจะสวยขึ้นมาก
4. **โลโก้แบบเส้นเดียว (monochrome)** สำหรับใช้บนรูปสว่าง (ตอนนี้โลโก้ทองต้องมีเงาเข้มรองหลังรูปแชร์)
5. **ฟอนต์ CJK บนรูปแชร์**: ถ้าแบรนด์อยากให้ชื่อจีน/ญี่ปุ่นขึ้นบนรูปแชร์ ต้องเพิ่มฟอนต์ subset (ไฟล์ใหญ่) ให้ฝ่ายเว็บทำ
6. ทบทวนป้าย **AD**: นโยบายตอนนี้ใช้ Event เป็นหลัก ถ้าบอสไม่รับงานโฆษณาเลย อาจตัดตัวเลือก AD ออก
