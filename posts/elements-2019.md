Elements เป็นห้องอาหารเชิดหน้าชูตาของโรงแรมOkuraที่กรุงเทพ ที่ได้รางวัลMichelin starหนึ่งดวง จากการจัดอันดับของมิชลินไกด์กรุงเทพประจำปี2019 Elements เป็นห้องอาหารที่ได้อิทธิพลมาจาก ห้องอาหาร Ciel Bleu ห้องอาหารมิชลินสตาร์สองดาวที่โรงแรมโอคุระ อัมสเตอร์ดัม ซึ่งแสดงออกมาในอาหารของ Element พอสมควรเรียกว่าพอมีกลิ่นอายจางๆ ทั้งการตั้งชื่อเมนู,สไตล์การปรุงรสแบบอาหารดัชซ์ และแน่นอนความครีเอทีฟในจานอาหาร แต่ในความรู้สึกของผู้เขียนแล้ว Elements ดูจะใส่ความเป็นญี่ปุ่นมากกว่าร้านต้นแบบพอสมควร ในทางตรงข้ามกันอาหารของ Elements นั้นกลับชวนให้ผู้เขียนนึกถึงร้านอาหารอีกร้านนึงในอัมสเตอดัมอย่าง Brod eau (มิชลินสตาร์หนึ่งดาว) มากกว่า ตรงที่ีชอบใช้ส่วนประกอบในจานเป็นอาหารทะเลตัดด้วยความสดชื่นของพืชผัก อย่างมากมาย การปรุงรสที่เน้นการใช้รสเปรี้ยวนำตัดกับรสเค็ม ส่วนตัวคิดว่าอาหารของ Elements นั้นมีมาตรฐานการปรุงที่ดี วัตถุดิบที่ดีรสชาติที่เป็นกลาง แต่ความรู้สึกมันยังขาดอะไรบางอย่าง ตัวเชฟพยายามสอดแทรกลูกเล่นความเป็นญี่ปุ่นลงในอาหารฟรั่งเศสเจือกลิ่นอายดัชซ์นิดๆ ลูกเล่นในบางจานนั้นว้าวเอาเสียมากๆ แต่บางลูกเล่นดูซ้ำซากและจำเจ เช่นส้มยูสุ ที่เราจะพบกว่า 70 % ของมื้ออาหารนี้ การจับคู่วัตถุดิบที่ดูพยายามใส่ความเป็นญี่ปุ่นลงไปในจานอาหารจนทำให้มันไม่คลิกเสียทีเดียว อีกอย่างนึงที่ผมรู้สึก คือการจัดลำดับจานที่ทีมงานของเราค่อนข้างงง Element เปิดคอร์สมาด้วยรสอ่อนๆสักจาน คั่นด้วยรสจัดสักจาน ก่อนกลับไปรสอ่อนมากๆอีกสองจาน แล้วโดดไปจานที่รสจัดจ้านมากๆในเมนท์คอร์ส ซึ่งส่วนตัวรู้สึกไม่ค่อยต่อเนื่องมีความเป็นคอร์สสักเท่าไหร่ และรสชาติของเมนคอร์สนั้นดูโดดหลุดออกมาจากอาหารทุกจานในคอร์สเลยทีเดียว

ในส่วนของการบริการ Element ทำได้ดีทีเดียวครับ การบริการมีมาตรฐานสมกับความเป็นโอคุระและร้านอาหารลือชื่อ ทั้งการหมั่นสอบถามรสชาติที่ผมว่ามากจนถึงระดับที่บางคนอาจจะไม่ชอบไปได้เลย การเก็บเศษขนมปัง การเก็บผ้าเช็ดปากและเก้าอี้เวลาเราเข้าห้องน้ำ แต่มีจุดเล็กๆน้อยๆที่ผมไม่ชอบอย่างอุณหภูมิแอร์ที่ค่อนข้างร้อนไปสักนิด หรืออย่างเมื่อถามถึงรายละเอียดอาหารที่นอกสคิป ทางสต๊าฟจะติดสตันท์และตอบแบบงงๆทันที ตัวอย่างเช่น ผู้เขียน“อะไรที่ออนท็อปอยู่ข้างบนจานนี้ครับ” บริกร“ผักคะ” ถถถถถรู้แล้วว่าผัก ผักอะไรละครับบบบ ถ้าเทียบกันแล้วผมว่าการอธิบายอาหารของร้านทางฝั่งยุโรปจะดูน่าสนุกกว่ามากเพราะบริกรจะอธิบายด้วยความเข้าใจและเปลี่ยนมาเป็นสำนวนเฉพาะตัว โดยเฉพาะร้านอาหารในอัมสเตอร์ดัมร้านนึงผมเคยเจอการอธิบายอาหารจานนึงเหมือนคุยเล่นกันมากกว่า คุยไปคุยมาตั้งแต่เชฟได้แรงบันดาลใจจากอะไรเมือไหร่ยังไง วัตถุดิบนี้เอามาจากไหน ยันเทคนิคการปรุง รวมๆแล้วสองสามนาทีก็มี

สำหรับเมนูของ Element นั้นจะมีสองคอร์สคือ คอร์สเล็กในราคา 4000 และ คอร์สใหญ่ในราคา 4400 ซึ่งนับว่ามีราคาไม่สูงมากนัก เมื่อเทียบกับคุณภาพวัตถุดิบ สถานที่ ปริมาณที่ให้ในแต่ละจาน ซึ่งในวันนี้ผมได้ ผมได้สั่ง Matsu คอร์สในราคา 4400บาท จะมีอะไรบ้างไปดูจากรูปได้เลยครับ

## ศิลปะแห่งรสชาติในมื้อนี้

### Kombucha
image: ./images/elements-2019/01.jpg | แก้วไวน์เปล่า แก้วคอมบุฉะสีทองและถ้วยแก้วใส่ถั่วแดงบนโต๊ะอาหาร ร้าน Elements กรุงเทพ
เครื่องดื่มล้างปากของเราเป็นคอมบุฉะ KombuchaของElementsยอดเยี่ยมมากครับ หวานเปรี้ยวกำลังดีไม่เหม็นกลิ่นของดอง มีรสหวานของน้ำผึ้งและความหอมกลิ่นกุหลาบที่ปลายลิ้น อร่อยจนอยากขอสูตรเลยทีเดียวครับ

### Amuse Bouche
image: ./images/elements-2019/02.jpg | ครีมสีขาวท็อปซอสแดงบนแครกเกอร์เหนือถ้วยแก้วใส่ถั่วแดง ร้าน Elements กรุงเทพ
มาถึงในส่วนของ Amuse Bouche กันบ้างโดยพนักงานจะยกมาทีตูมเดียว ขนมปังกับครีมUni ที่ถูกตีขึ้นด้วยเทคนิคเอสพูม่า และCompoteบ๊วยก่อนโรยหน้าด้วยฟูริคาเคะ คำนี้อร่อยเลยครับ ครีมเอสพูม่าอูนิแสนครีมมี่เค็มอมหวานตัดกับรสเปรี้ยวหวานของบ๊วยได้อย่างพอดี เพิ่มความกลมกล่อมอูมามิด้วยฟูริคาเคะด้านบน นับเป็นคำที่ลงตัวดีเลยครับ คำต่อมาเป็นแครกเกอร์สาหร่ายกับเต้าหู้มิโซะและซอสนิซึเนะผสมยูซุ คำนี้ผมว่าการจับคู่ของที่รสอ่อนอย่างเต้าหู้นั้นทำได้ไม่ค่อยดี ผมได้แต่กลิ่นแป้งแคร็กเกอร์เต็มปาก คำนี้คือแครกเกอร์ข้าวเกรียบผสมถ่านกับทูน่า ตัวแป้งบางกรอบแบบข้าวเกรียบกัดปุ๊ปละลายปั๊ป ทูน่าติดรสเค็มนิดๆ ซอสเปรี้ยวหวานคล้ายพิซซ่า ใช้ได้เลยครับ อีกคำนี่เป็นกระทงทองโอโคโนมิยากิ ทำมาได้เก๋ดีเลยครับและรสชาติดีทีเดียว กระทงทองแป้งกรุบๆกับไส้ตรงกลางรสเปรี้ยวหวานหอมกลิ่นขิงจางๆ ชวนให้นึกถึงโอโคโนมิยากิจริงๆ ผมชอบเลยนะ

### Bread
image: ./images/elements-2019/03.jpg | ขนมปังก้อนกลมสีดำโรยงากับบาเกตบนจานเหลี่ยมสีขาว ร้าน Elements กรุงเทพ
มาถึงขนมปังและเนยกันบ้าง ขนมปังของทางร้านนั้นผมว่าค่อนข้างอร่อยเลยครับ โดยเฉพาะตัวเนยผสมมิโซะและสาหร่ายรมควันที่มีกลิ่นหอมโดดเด่นมีเอกลักษณ์เฉพาะตัว แปลกอร่อยดี ในส่วนของขนมปังนั้นมี ขนมปังผสมคิโนโกะ ขนมปังชาโคลล และครัวซองครับ(ไม่มีในรูป )

### Toro tuna
image: ./images/elements-2019/04.jpg | ทูน่าโทโร่สับกับผักดองสีสดใสบนซอสครีมในชามขาว ร้าน Elements กรุงเทพ
จานแรกในวันนี้คือ Toro tuna เป็นคาปัชโช่ชูโทโร่ กับหอยนางรมดิบ และครีมหอยนางรม รับประทานกับผักดองสารพัดชนิดและซอสเบลอบล็องที่ทำจากดาชิแบบญี่ปุ่นผสมแชมเปญ จานนี้ผมประทับใจที่สุดในมื้อนี้เลยครับ อร่อยมาก การจับคู่ชูโทโร่ที่มีความมันนิดกับหอยนางรมอันแสนหวานที่มีกลิ่นทะเลนิดๆนั้นลงตัวอย่างไม่น่าเชื่อ รสหวานของซีฟู้ดคุณภาพดีถูกชูให้เด่นขึ้นมาด้วยซอสเบลอบล็องที่ยอดเยี่ยม มันมีรสเค็มแบบญี่ปุ่นด้วยดาชิและรสเปรี้ยวปลายลิ้นแบบตะวันตกหน่อยๆ ก่อนจะตัดความมันของซอสด้วยความเปรี้ยวหวานของผักดอง ที่มีลูกเล่นนิดนึงคือการดองในสองสไตล์ทั้งแบบญี่ปุ่นและตะวันตก ก่อนจะเพิ่มกลิ่นอายความเป็นญี่ปุ่นขึ้นอีกนิดด้วยพอนซึเจลลี่ จานนี้ผสมผสานญี่ปุ่นและตะวันตกได้อย่างลงตัวในจานเดียวยอดเยี่ยม

### Japanese sea
image: ./images/elements-2019/05.jpg | โฟมขาวฟูปกคลุมปลาและหอยเชลล์กับสาหร่ายบนซอสใสในชามปากกว้าง ร้าน Elements กรุงเทพ
จานต่อมาในวันนี้เป็น JAPANESE SEA จานนี้มีส่วนประกอบคือโฟมที่ทำจากหอยอาซาริ ซอสแอชโชวี่ เนื้อปลาหมึกยักษ์ ปลาฮามาจิ หอยเชลล์ และสาหร่ายสด จานนี้มีความสนุกจากวัตถุดิบที่หลากหลาย แต่ส่วนตัวผมว่ากลิ่นอายความเป็นทะเลของโฟมหอยอาซาริถูกกลิ่นของแตงกวาดึงความเด่นเอาไปเสียหมดจนพุดว่าเป็นทะเลได้ไม่เต็มปาก สาหร่ายสดเองก็ถูกโฟมกลบเท็กเจอร์ไปจนหมด รสชาติครึ่งๆกลางๆจะทะเลหรือแตงกวาดีนี่จานนี้

### Hokkaido scallop
image: ./images/elements-2019/06.jpg | หอยเชลล์ย่างวางบนซอสเขียวเข้มท็อปด้วยผักวอเตอร์เครส ร้าน Elements กรุงเทพ
จานต่อไปเป็น หอยเชลล์จากฮ็อกไกโดย่างกับซอสวอเตอร์เครส ออนท็อปด้วยอิคุระและ ครัมเบิ้ลจากมันฟรั่ง คำนี้หอยเชลล์ย่างมาได้ดีมากๆๆครับ สุดกรอบที่ผิว เนื้อหอยเชลล์ด้านในสุกกำลังดีมีรสหวาน รสของหอยเชลล์ถูกชูให้เด่นชัดด้วยอิคุระรสเค็มและซอสวอรเตอร์เครสที่ขมนิดๆ แต่สิ่งที่ผมชอบที่สุดในจานนี้คือมันฟรั่งครัมเบิ้ลที่มาเป็นชิ้นเล็ก ที่ช่วยเพิ่มมิติในปากให้กับจานนี้ได้อย่างมีชั้นเชิงและกลิ่นมันฟรั่งยังเข้ากับหอยเชลล์ได้ดีอีกด้วย

### Seabass
image: ./images/elements-2019/07.jpg | ปลาซีบาสห่อสาหร่ายท็อปต้นหอมซอยบนน้ำซุปสีอำพันกับปลาหมึก ร้าน Elements กรุงเทพ
จานนี้คือ เมดิเตอรเรเนียนซีบาสห่อด้วยสาหร่าย รับประทานกับดาชิผสมยูสุออย ข้างบนท็อปด้ว “ผักคะ”(ความจริงคือลีค) ด้านล่างใส่ปลาหมึกยักษ์ฝานบางๆ ส่วนตัวผมไม่ชอบจานนี้ เพราะตัวปลาเท็กเจอร์แปลกๆกึ่งสุกดิบ จับคู่กับปลาหมึกยักษ์ที่แม้จะปรุงมาได้ดีนุ่มไม่เหนียวแต่ผมว่าไม่มีก็ไม่ทำให้องค์ประกอบในจานนี้หายไป ตัวซอสดาชินั้นรสคล้ายๆซอสบะหมี่เย็นเค็มจนกลบความหวานของปลาและรสจัดหนักจนค่อนข้างเลี่ยน สำหรับกลิ่นส้มยุสุออยนั้นไม่ค่อยได้กลิ่นถ้ามียุสุคงจะดีกว่านี้

### Short rib
image: ./images/elements-2019/08.jpg | เนื้อชอร์ตริบโรยมันฝรั่งทอดชิ้นเล็กราดซอสไวน์แดงข้างหน่อไม้ฝรั่ง ร้าน Elements กรุงเทพ
เนื้อจานนี้พนักงานบอกกับเราว่าซูวีมาสี่สิบแปดชั่วโมง โดยเชฟเลือกเสิร์ฟเป็น Short rib ตัวเนื้อเสิร์ฟมาพร้อมกับ หัวเทอนิฟ หน่อไม้ฟรั่ง แชลลอตพิวเร่ ครัมเบิลจากมันฟรั่ง จานนี้ผมว่าเลี่ยนจนเกือบทานไม่หมด รสจัดเข้มข้นเกินไป ตัวซอสไวน์แดงขาดความลึกทำได้ดีแต่ยังไม่รู้สึกว้าวแบบห้องอาหารฟรั่งเศสมิชลินสตาร์ทุกแห่งในไทย เป็นจานที่ค่อนข้างไปนิดเมื่อคำนึงถึงจานอื่นๆในคอร์ส จานนี้ทำให้ผมรู้สึกถึงบุตะคาคุนิที่รสเข้มมากๆ โดยส่วนตัวไม่ประทับใจครับ

### Pre dessert
image: ./images/elements-2019/09.jpg | เมอแรงค์ขาว ลูกกลมสีเหลืองและแยมแครนเบอร์รีบนกระดาษกินได้บนถาดโลหะ ร้าน Elements กรุงเทพ
พาเลทคลีนเซอร์ของเราเป็น กระดาษกินได้ทำจากข้าวญี่ปุ่น ตบแต่งด้วย บัลดออเร้นจ์ เมอแรงค์ แคนเบอรรี่แยม และถั่วพิทาชิโอ้ ใช้ได้เลยครับรสเปรี้ยวนิดหวานหน่อยจากส้มและแครนเบอรรี่ ความกรุบๆของถั่วพิทาชิโอ้ ครีเอททีฟดีและอร่อยดีเลยนะ ถ้ากระดาษนั้นบางลง ส่วนตัวว่ากระดาษหนาไปนิดทำให้เท็กเจอร์แปลกๆไปบ้าง เหมือนกินกระดาษจริงๆซึ่งไม่ค่อยน่าอภิรมย์เท่าใดนัก

### Mango
image: ./images/elements-2019/10.jpg | ซอร์เบต์มะม่วงล้อมด้วยทรงกลมสีเหลืองและเมอแรงค์บนฐานครัมเบิล ร้าน Elements กรุงเทพ
ขนมหวานจานแรกของเราคือแมงโก้ซอเบท รับประทานกับ ยุสุเคิร์ท(curd) เมอแรงค์ ครัมเบิล ก็อร่อยดีครับ ส้มยุสุกับมะม่วงให้รสเปรี้ยวหวาน มีครัมเบิลช่วยเพิ่มเท็กเจอร์ แต่ไม่ได้รู้สึกว้าวแตกต่างจากที่อื่น

### Gomasio
image: ./images/elements-2019/11.jpg | มูสช็อกโกแลตทรงแท่งบนจานเซรามิกดำข้างขนมชิ้นเล็กสีส้มและเขียวอ่อน ร้าน Elements กรุงเทพ
อีกจานเป็นดาร์คช็อคโกแลตมูส เสิร์ฟมาพร้อมซอสงาดำ ยุสุเจล ยุสุเจลลี่ กล้วยเคลือบน้ำตาลทราย น้ำตาลแห้งจากผลอินทผลัม และช็อคครัมเบิล ส่วนตัวผมชอบจานแรกมากกว่าครับจานนี้รสของมูสที่ออกขม ค่อนขคอนทราสกันแรงไปกับสารพัดส้มยุสุที่เปรี้ยวโดด ยิ่งเพิ่มความขมของครัมเบิ้ลด้วยยิ่งแล้วกับไปใหญ่ แม้จะมีกล้วยที่หวานมากๆ พยายามมาช่วยตัดแล้ว แต่ละชิ้นกินเดี่ยวๆคงจะอร่อยดีเลยนะครับแต่พอมารวมเป็นจานเดียวกันแล้ว ผมรู้สึกถึงความไม่กลมกลืนเป็นอาหารจานเดียวกันในขนมหวานชุดนี้

### Petit four
image: ./images/elements-2019/12.jpg | ขนมคำเล็กหลายชนิดในกล่องแล็กเกอร์สีแดงเข้มโรยถั่วแดง ร้าน Elements กรุงเทพ
สำหรับ Peitifour ของ Elements ผมค่อนข้างผิดหวังครับ ประกอบด้วย มาการองสองสีเป็นงากับอัลม่อนใส่ไส้ยุสุ ตัวนี้อร่อยครับรสเปรี้ยวของไส้ตัดกับรสหวานอย่างลงตัวหอมกินงาและยุ มันทฉะมูสกับยุสุคาเวียร์ คำนี้ครีมมี่ติดเปรี้ยวนิดๆ แต่ผมไม่ได้กลิ่นของมัทฉะกะยูสุ วาเลนเซียเค้กกับส้มยุสุ ดาร์คช็อคโกแลต ด้านในมีไส้กรอบๆโดยส่วนตัวว่าหวานไปนิดครับ
